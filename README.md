# 🌐 B2B Commodity Export Negotiator

A professional, lightweight web application designed to streamline international trade communications, draft export agreements, and assist in cross-border commodity negotiations.

---

### ✨ Key Features
* **Automated Trade Communication:** Generates structured export proposals and negotiation drafts.
* **AI-Powered Insights:** Integrated with modern AI APIs to assist in drafting precise B2B correspondence.
* **Lightweight & Fast:** Built using pure HTML5, CSS3, and JavaScript—runs entirely in the browser.

---

### 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Integration:** REST APIs / LLM endpoints
